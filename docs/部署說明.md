# 部署說明（讀書會試跑）

整個網站分兩半：前台放 GitHub Pages（公開，只有網頁程式，沒有任何同學的資料）；後台是 Google Apps Script，資料存在你的**私人** Google Drive 資料夾。

## 一、Google Drive

1. 裝「Google Drive 電腦版」，登入你的 Google 帳號。
2. 在「我的雲端硬碟」開一個資料夾，例如 `第三條路試跑`。**不要開公開分享**。
3. 打開這個資料夾，網址最後那一串（`folders/` 後面）就是資料夾 ID，等一下要用。
4. 電腦版會把它同步成本機資料夾（通常是 `G:\我的雲端硬碟\第三條路試跑`）。把這個路徑告訴 Claude，跑報告時就直接讀寫這裡。

## 二、後台（Apps Script）

1. 到 https://script.google.com 新增專案，名稱取「第三條路試跑後台」。
2. 把 `backend/Code.gs` 的內容整份貼進去，存檔。
3. 左邊齒輪「專案設定」→「指令碼屬性」，新增四個：
   - `ROOT_FOLDER_ID`：第一步的資料夾 ID
   - `INVITE`：邀請碼（自己訂，例如 `reading2026`，發在讀書會群組）
   - `OWNER_EMAIL`：你的 Email（有人送出、確認、回答、填回饋時通知你）
   - `SITE_URL`：前台網址，例如 `https://albertchien-oa.github.io/decision-pilot`（結尾不要斜線）
4. 右上「部署」→「新增部署作業」→ 類型選「網頁應用程式」：執行身分「我」、存取權「所有人」。第一次會要你授權 Drive 和寄信，照著按允許。
5. 複製拿到的網址（結尾是 `/exec`）。
6. 左邊鬧鐘「觸發條件」→ 新增：函式選 `notifyChanges`、時間驅動、每 10 分鐘。這樣你在資料夾裡改了階段，同學會收到信。

## 三、前台（GitHub Pages）

1. 把 `assets/config.js` 的 `API_URL` 改成上一步的 `/exec` 網址。
2. 跟 Claude 說「上架 GitHub」，資料夾是 `decision-pilot`。
3. 打開網站，用一組假資料從頭填到送出，確認 Drive 資料夾出現 `P01_xxxxxxxx`、你收到通知信。測完把那個資料夾刪掉，並在 Apps Script 的指令碼屬性把 `COUNTER` 改回 `0`、刪掉那一筆 `T_` 開頭的屬性。

## 四、資料夾裡有什麼（每份一個 `P01_xxxxxxxx`）

| 檔案 | 誰寫的 | 用途 |
|---|---|---|
| `00_用戶描述.md`、`個人檔案.md` | 後台（同學送出時） | 跑報告的輸入 |
| `聯絡.md` | 後台 | 只給你，不給任何 AI 步驟 |
| `公司調查區/公司.md` | 後台 | 只給公司調查那一步 |
| `附件/` | 後台 | 同學上傳的檔案 |
| `狀態.json` | 後台建立，**Claude 改** | `stage` 決定同學在進度頁看到什麼：`received` 收到、`card` 確認問題卡、`questions` 回答追問、`making` 製作中、`done` 報告好了、`declined` 這次不製作；`message` 是顯示在最上面的一句話；`pilotNote` 是報告上方的註記（例如第三條路沒到標準）；`declineReason` 是不製作的說明 |
| `問題卡_給用戶.md` | Claude | stage 是 `card` 時給同學看 |
| `問題卡_用戶回覆.md` | 後台 | 同學確認問題卡時寫的修改 |
| `追問.json` | Claude | `{"questions": ["第一題", "第二題"]}`，stage 是 `questions` 時給同學回答 |
| `追問答案_第1輪.md` | 後台 | 同學的回答 |
| `報告_給用戶.md` | Claude | stage 是 `done` 時線上顯示 |
| `人生模擬.json`、`一句話.json` | Claude | 報告頁的人生模擬和一句話 |
| `交付/` | Claude | 放 Word、PDF，同學可以下載 |
| `回饋.json` | 後台 | 同學填的回饋 |

## 五、注意

- 進度連結裡的那串亂碼就是同學的鑰匙，信裡會提醒不要轉給別人。
- 後台用你的 Gmail 寄信，Google 一般帳號每天上限約 100 封，試跑夠用。
- 試跑結束 30 天內，照同意說明刪掉每份的資料夾。

## 六、初階報告和帳號（2026-11-09 加）

新流程在 `begin.html`：用 Email 註冊（驗證碼）→ 寫下卡住的事 → Claude Haiku 整理成問題卡 → 補幾題 → 扣 10 點看初階報告。新帳號只送一次 10 點。

**你要做的（照順序）：**

1. **開 Anthropic API 帳戶**：到 console.anthropic.com 註冊、綁卡、建一把 API 金鑰。建議在 Console 設每月花費上限。
   - 建金鑰時跳出「連接至 Claude API／您的程式碼在哪裡執行？」四個選項：選右下角**「其他地方：使用 API 金鑰」**。前三個（自己的電腦、雲端、CI）是給工程師在自己機器或伺服器上用的免金鑰登入，Apps Script 用不了。
   - 金鑰名稱隨便取（例如 `pathwise-apps-script`）。建好後那串 `sk-ant-` 開頭的字**只會顯示這一次**，馬上複製，直接貼進第 3 步的 Apps Script 指令碼屬性；不要存成檔案、不要貼到聊天。弄丟了就刪掉重建一把。
2. **建帳號表**：在存資料的私人 Drive 開一個新的 Google 試算表，名字隨意，第一個工作表留空（程式會自己寫標題列）。複製網址裡 `/d/` 和 `/edit` 中間那段 ID。
3. **Apps Script 加三個指令碼屬性**（專案設定 → 指令碼屬性）：
   - `ACCOUNTS_SHEET_ID`：上一步的 ID
   - `ANTHROPIC_API_KEY`：第 1 步的金鑰（只放這裡）
   - `CARD_DAILY_CAP`：全站每天最多整理幾張問題卡，試跑先填 `50`
4. **貼程式碼**（Apps Script 左邊「檔案」→＋→ 指令碼）：
   - `Code.gs`：用 repo 的新版整份蓋掉（多了一行接 Account.gs）
   - `Account.gs`：新增，貼 repo 的 `backend/Account.gs`
   - `初階報告_引擎.gs`、`初階報告_資料.gs`：新增，貼本機 `1in8b-research/decision-report/overview/_給AppsScript/` 裡的兩個檔。**這兩個不放公開 repo**（段落庫和提示詞是產品內容）。改了段落庫就重跑 `python -X utf8 build_gs.py` 再重貼。
5. **重新發布**：部署 → 管理部署作業 → 編輯 → 版本選「新版本」→ 部署。網址不變。
6. **第一次執行會要授權**：新的程式會用到試算表、寄信、連外部網址，照畫面按允許。
7. **開讀書會的試跑帳號**：在 `Account.gs` 最上面改 `TEST_EMAILS`（同學的 Email）和 `TEST_POINTS`，在編輯器選 `adminCreateTestAccounts` 按執行，執行紀錄會印出每個人的密碼，抄到本機的帳密清單（不進 git、不貼到聊天）。試跑結束執行 `adminDisableTestAccounts` 全部停用。
8. 都好了告訴我，我會用一個測試帳號從註冊走到初階報告，確認沒問題才把首頁推上線（首頁按鈕已經改連 `begin.html`，還沒推）。

**花費**：每張問題卡呼叫一次 Haiku（輸入約 1,500 字、輸出約 500 字，照 Haiku 5.5 的價格，一張不到台幣 1 毛）；初階報告本身照規則產生，不花錢。
