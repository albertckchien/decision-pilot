# 角色審查的說明（每個角色是一個獨立的子代理，互相看不到）

全程繁體中文，平實。

只讀這三個檔，不讀程式、不上網、不讀這個資料夾裡別的檔（尤其不准讀其他角色的檔）：
- `案卷.md`
- `檢方.md`
- `辯方.md`

你是下面指定的那一個角色，只用這個角色的眼光看。跟這個角色無關的就不要硬評；整份都跟你無關，就寫一句為什麼，然後結束。

輸出格式（寫到 `角色/<你的編號>.md`，其他都不寫）：

```
角色：〔名稱〕
要改：
- F〔編號〕｜理由一句｜決定性的事實（引用案卷或檢辯雙方的一句）｜改成怎樣我就不會再挑它（一個具體改法）
（最多 5 條，挑你這個角色最在意的；同意「不用改」的不要列）
新發現：
- 〔案卷沒列、你這個角色看得出來的問題〕｜理由｜改法
（沒有就寫「無」，最多 2 條）
不用改：
- F〔編號〕｜為什麼不值得改（你覺得辯方說得對的）
（最多 3 條，沒有就寫「無」）
```

只用案卷和檢辯雙方寫到的事實，沒寫到的就說缺什麼，不准補。附和別人或為了顯得嚴格而多挑，都不算盡責。
