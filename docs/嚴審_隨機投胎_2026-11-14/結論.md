## 複審（15 條，7 該修、8 小事，沒有擋上線）
修了 13 條：0 次抉擇的成年局不再說「太短」、念書的人不再寫「沒有工作」、`start` 降精度、`FIELDS.json` 改逐欄物件並真的拿來比、結婚和裁員上限有標、惡性通膨代表值 70→120、資料來源連結開新分頁、表單填 0 不再變 30、授權範圍補政變標籤和不含 Pew、資料檔帶版本號、國名掃描加抉擇卡、健康係數註解改成實測、重病提示不再講健保。

## 獨立重審（15 條，1 擋上線、9 該修、5 小事）
逐條對回程式驗證，15 條都成立，全部修了：
- 擋上線：1996 年以前就走完的一生，結局說「沒有遇到戰亂」→ 改成「這段年份的國家大事這裡沒有資料」，活過 1996 的寫「1996 年以後，…」。
- 衰退次數同一年重複算 → 照年份去重；倒債、惡性通膨也算進去。
- 「跳到下個抉擇」後存款最高算少 → 改在引擎記 `p.peak`，結局和分岔共用。
- 積極治療在醫療照顧很低的國家反而比保守差 → 保守治療的治癒率是積極的一半。
- 「逃到國外最安全」跟逃到國內一樣 → 逃到國外不再受戰火波及；提示改寫。
- 休學去工作其實沒工作、學歷又被改回中學 → 15 歲起開始工作、學歷停在小學。
- 真實年份的貨幣危機不動存款、倒債說「限制提款」 → 歷史年份會打折存款；倒債那句改寫。
- 退休說有年金、程式沒有 → 公職和公司領最後薪水四成，其他沒有；退休後照扣生活費（原本退休後開銷是 0，存款只會變多，這是主 session 驗證時多找到的）。台灣退休後活過 75 歲的人 134／162 存款變少。
- 0 歲開局多擲一次骰子 → 推估年份不先呼叫 `year()`。
- 出生機率印「0.0 個」 → 改成「每 1 萬個有 N 個」。
- 技職「兩到四年」→「四年」；結婚、裁員上限拿掉「交給系統」字樣、提示講清楚；狀態列年紀改讀引擎；平均餘命改說「照現在的死亡率算」；FIELDS 逐欄寫實際來源。
