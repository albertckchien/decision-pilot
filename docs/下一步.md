- **先做免費初步分析**：首頁不要一上來就推報告。先請路人隨便寫一件卡住的事或兩難，當場給一份不花 AI 額度的初步分析（照 `1in8b-research/decision-report/templates/overview_template.md` 的規則產生），看完才出現三種報告和 1～2 份範例報告；認真要問的人再「登入」用送的點數跑分析報告，或付款。

  - 做法：Apps Script 後台多一張帳號表（帳號、密碼的雜湊、剩餘點數、啟用或停權），加上登入和扣點的動作；停權後該帳號的連結和登入都失效。
  - 帳密清單只存在本機（不進 git），用戶自己發；密碼不寫進聊天紀錄。
  - 正式的註冊、付款等正式上線前另外做。
