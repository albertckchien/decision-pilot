# 人生模擬引擎 v1（2026-11-03）

照 `../docs/人生模擬設計.md` 和示意頁 v2（用戶 2026-11-03 同意）。報告寫完後在我們這邊先跑，結果存成 `人生模擬.json` 放進同學的 Drive 資料夾，報告頁的 `assets/sim.js` 負責播放。

```
node simulate.js <人生模擬參數.json> <人生模擬.json> [--runs 500] [--seed 1]
```

## 每一年怎麼擲
1. 國家（`world.js`）：全球衰退、衰退和成長、貨幣危機、通膨、地震和颱風，照 `1in8b-research/country-data/estimated/trends/rules.json` 和 `country_hazards.csv`；住哪國照選項的階段。
2. 個人（`simulate.js`）：收入（選項的年薪 × 國家成長帶動的加薪，衰退那年裁員機率高）、稅約 15%、支出隨物價和年紀增加、小孩上大學的花費、存款報酬；選項自己的事件（機率和影響由寫報告那一步照報告填）；家人（小孩里程碑、爸媽需要照顧）；健康隨年紀下降、生病；生活小事。
3. 壽命：生命表（國家、年、年紀），沒問性別就取男女平均。
4. 句子在 `texts.js`，固定句型，不用 AI 即時生成。

## 怎麼挑運氣好、運氣差
每個選項跑 500 次，用戶排的三個目標（事業、家庭、存款、健康）在所有選項、所有次裡排百分位，照 3、2、1 加權，壽命只占 0.5；取第 80、20 百分位附近那一次。三個選項的中位分數差得少，報告頁的一句話用「放輕鬆」，差得多用「分水嶺」。

## 參數檔
範例：`example_派駐新加坡.json`。`options[].phases` 寫每段住哪國、年薪、另一半收入；`options[].events` 寫這個選項特有的事（`p` 每年機率、`at` 第幾年到第幾年、`once`、`group` 同組只會發生一件、`effect` 的 m 存款萬元、h 健康、f 家庭、c 事業、income 收入倍數）。

## 還沒做（v1 的限制）
- 戰爭、政變、組織性暴力、倒債的規則還沒接；通膨級距沒有逐年轉移，先照現在的級距（有貨幣危機升兩級）；貨幣危機的 infl_hi 先用「通膨 20% 以上」代替。
- 個人的事（升遷、生病、裁員）的機率是粗估，不是統計資料。
- 存款沒算房貸本金和保險，金額只看趨勢。
