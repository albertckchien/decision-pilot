# 人生模擬參數（人生模擬參數.json）的格式

寫報告那一步產這份檔，`check_params.js` 檢查過才跑 `simulate.js`。範例：`example_派駐新加坡.json`。

**金額一律用「今天的錢」、單位是萬元（新臺幣）**；年數 `t` 從 0 起算，0 是今年。

## 最上層

| 欄位 | 必填 | 說明 |
|---|---|---|
| `case` | 是 | 一句話，給工作人員看（不出現在畫面上） |
| `start_year` | 是 | 今年（西元） |
| `age` | 是 | 客人現在幾歲 |
| `gender` | 是 | `M` 或 `F`。個人檔案沒填就問；問不到用 `M`，並寫進 `assumptions` |
| `home` | 是 | 客人現在住的國家，ISO3 代碼（台灣 `TWN`） |
| `savings` | 是 | 現在的存款（萬）。負債寫負數 |
| `monthly_spend` | 是 | 家裡每個月的固定支出（萬） |
| `retire_age` | 否 | 幾歲退休，沒寫用 63 |
| `pension_monthly` | 否 | 退休後每個月的年金（萬），沒寫用 2.5 |
| `family` | 是 | 見下面 |
| `goals` | 是 | 客人排的前三個人生目標，照順序，每個 `{ "name": 原話, "metric": career / family / wealth / health }` |
| `titles` | 是 | 這個人所在行業的職稱階梯，由低到高，4～7 個 |
| `title_index` | 是 | 現在在階梯的第幾個（0 起算） |
| `sensitive` | 是 | 問題卡寫到重病、喪親、離婚、債務壓力、失業時是 `true`（不出「放輕鬆」「沒選的那條路」那兩類句子） |
| `has_actions` | 是 | 報告有行動建議（完整報告，或分析報告有寫第一步）就是 `true` |
| `options` | 是 | 2～4 個選項，見下面 |
| `assumptions` | 是 | 文字陣列：每個不是客人給的數字都寫一條（例如「年金照台灣勞保平均估 2.5 萬」） |

## family

| 欄位 | 說明 |
|---|---|
| `kids` | 小孩現在的年紀，陣列；沒有就 `[]` |
| `parents_age` | 媽媽現在幾歲（爸爸自動多 2 歲）；爸媽都不在了就不寫 |
| `spouse` | 沒有另一半就寫 `false` |
| `spouse_gender` | 不寫就跟 `gender` 相反 |
| `spouse_age_gap` | 另一半比客人大幾歲，小就寫負數，沒寫用 −2 |

## options[]

| 欄位 | 說明 |
|---|---|
| `id` | A、B、C… 跟報告比較表一樣 |
| `name` | 報告裡的名稱（短） |
| `sub` | 一句補充 |
| `phases` | 這條路分幾段，每段 `{ from, to, country, income, spouse_income, family_together }`：第 `from` 年到 `to` 年（不含 `to`）住在 `country`、年收入 `income`（萬）、另一半年收入；全家不在一起時 `family_together: false`。最後一段的 `to` 寫 99 |
| `events` | 這條路自己會發生的事，見下面；報告裡寫到的風險和機會，有機率的才放 |

## events[]

| 欄位 | 說明 |
|---|---|
| `text` | 畫面上的句子，用「你」，平實，不用他／她 |
| `p` | 發生的機率（0～1），照報告的判斷；報告沒說就寫進 `assumptions` |
| `at` | `[第幾年起, 第幾年止]`，在這段時間裡每年擲一次骰 |
| `once` | 只發生一次就 `true` |
| `group` | 同一組的事只會發生一件（例如「照合約升遷」和「升遷保證沒了」） |
| `kind` | `big`（好事）、`hit`（壞事）或空字串 |
| `effect` | `{ f: 家庭, c: 事業, h: 健康, m: 存款（萬）, income: 收入變幾成（0.1 是多一成）, title: 升到的職稱 }`。**只有好事（`big`）可以帶 `title`** |
| `same_company` | 被裁員換過公司後就不會發生（例如合約裡的升遷）時寫 `true` |
| `below_title` | 職稱已經到這一級就不會發生（例如「升處長的保證沒了」寫 `處長`） |

## 限制（試跑先這樣）

- 國家用 200 國資料有的 ISO3 代碼。同事的名字：台灣、中國、港澳用台灣名字，新加坡混華、馬來、印度，日本用日本名字，其他國家用英語系名字。
- 畫面背景：台灣是 101，新加坡是濱海灣金沙，其他國家是沒有地標的街景，63 歲起是公園。
- 人生選擇一律保守，好壞只來自外在運氣；這份檔不准寫「客人選了 X 所以 Y」這種選擇。
